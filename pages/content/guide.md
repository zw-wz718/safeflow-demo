## 账户与连续对话

导航包含智能助手、账户总览、转账汇款、我的账单、银行卡和订阅管理。可以用聊天提出需求，也可以进入业务页查看结构化步骤。

### 查询余额

1. 登录后进入账户总览，点击读取或刷新余额，核对工资卡尾6628和当前可用余额。
2. 进入智能助手，发送“查询我的工资卡余额”。如需选择账户，请选页面提供的本人账户。
3. 观察回答中的账户、金额与数据时间；可以继续追问已有资料，不把聊天估计当作账面结果。

### 对话中的办理方式

模型可能先追问账户、收款人或参数，请从可信选项中明确选择。收到草案后，核对参数再按业务卡片继续；不要只发送“我授权一切”要求跳过验证。聊天和业务页的按钮文字略有不同，但付款信息、委托、模拟验证与最终提交必须分别完成。

### 放弃或改办

仅对尚未受理的草案使用“放弃这份未付款草案”，或填写“改办转账金额”后点击“放弃此未付款草案，改办新转账”。新金额需要重新核对和确认。过期草案由服务端按原期限处理；已提交或结果未知的付款请查询原记录，不能用新任务作废。

### 等待与恢复

模型理解需要等待。不要在等待时反复发送同一写需求。出现超时或登录失效时，重新登录并查看原业务；只有状态明确表明尚未受理且允许重新准备时才开始新操作。

## 100元模拟转账

下面是业务页的固定100元路径。先读取尾6628卡的当前状态；卡片可用、余额与授权等前置满足时，按步骤办理并查询实际到账结果。若卡片已冻结，流程会在安全检查处拒绝出账，此时联系组织者，不要尝试绕开拒绝。

### 核对草案

1. 进入转账汇款。核对付款账户工资卡尾6628，收款人李明远、示例银行、尾1024，金额100.00元。 首次点击“创建100元草稿”；已有可结束原任务时按钮可能显示“创建新的100元草稿”。随后才会出现草稿准备、确认与保存步骤。
2. 依次完成“准备草稿确认”“确认创建草稿”“保存模拟草稿”。如页面恢复的是已有草案，先核对原草案，不重复创建。
3. 确认草案中会显示完整模拟收款卡号；请核对其尾号1024及收款姓名，不把完整号发送到聊天。
4. 保存草案只代表资料已保存，没有扣款。点击“准备付款”，核对付款信息，再点击“确认此笔付款”。

### 委托与模拟验证码

1. 点击“查看独立后台委托”，阅读仅本笔原单、有效30分钟的说明，再点击“明确同意此笔后台委托”。聊天内对应按钮为“查看本笔后台委托”。
2. 在模拟验证区域点击“领取本次模拟验证码”，将显示的6位码手动填入付款验证码框。它是同设备演示码，不是真实短信。
3. 点击“核验付款验证码”；聊天内对应“核验模拟验证码”。领取验证码本身不会验证或付款。
4. 业务页最终按钮按已核快照显示金额：默认路径为“提交100元模拟付款”，其他金额应显示对应数值。只在草案、确认区与按钮金额一致，且页面允许继续时，明确自愿提交一次。

### 查看真实结果

已提交后可能先显示处理中并占用金额，后台沿该原单等待独立模拟结果，再进行最终事务。请使用页面的原结果查询，核对状态、付款编号和余额变化；只有实际结果显示完成才算到账。冻结、授权失效或未知结果不代表系统会立即成功，也不要重新创建另一笔。

### 对话转账

发送“从我的工资卡给李明远转100元”，沿聊天内展示的收款人、账户与金额选项准备草案，再完成付款确认、后台委托、模拟码和最终执行。成功或安全拒绝均以实际持久记录为准。

## 大额提示与付款恢复

大额体验用于观察风险提示与验证要求，不代表提高余额后任何金额都会获准。请先核对卡片状态；若已冻结，出账仍会被阻止。

### 测试大额提示

1. 只想观察提示时，先在智能助手准备“从我的工资卡给李明远转1000.01元”，明确选已有账户与收款人；准备草案本身不付款。
2. 核对金额及当前卡状态，按页面进入本笔确认阶段后阅读金额提示。若累计使用额加本笔超过1000元，应有Red强验证提示；冻结或其他前置拒绝仍是正常保护。
3. 只看提示就停止在资金受理前，不点最终“提交…元模拟付款”；可在未受理草案阶段明确放弃。若已受理/处理中，停止新建并按原编号查询，不能把放弃草案当成取消已付款。
4. 当前规则恰好1000元不会仅因金额门槛升Red，1000元不是硬限额。后台付款仍有本笔模拟码及委托要求，Yellow不表示免验证或低风险。实际大额付款仅由体验者另行自愿确认，不为复现文档连发付款。

### 怎样验证没有重复扣款

对已提交原付款使用原结果查询，核对付款编号、状态和流水；刷新或重新登录后再查同一记录，不另建一笔相同金额付款作为重试。业务页对“已受理且未终结”的原单若显示“撤销原后台续办”，可点击后查询原单核对撤销结果；它只停止后续委托，不撤销已发生交易、不保证立即释放占用或取消在途付款。聊天未显示该入口时，可回转账业务页先恢复原记录。

### 常见状态

| 看到的状态 | 应当怎么做 |
| --- | --- |
| 草案已保存或待确认 | 尚未付款；继续核对确认，或明确放弃未受理草案。 |
| 已确认或已验证 | 尚不等于完成；按当前步骤继续，不重复用旧验证码。 |
| 处理中或结果未知 | 查询原付款记录；不要重新提交新付款或要求清除占用。 |
| 确认或验证到期 | 按页面重新准备并确认，不能复用旧许可。 |
| 卡冻结或出账受限 | 停止付款，进入银行卡只读核对；当前无网页解冻入口。 |
| 已完成 | 核对原编号、余额和流水；需要核验时只读查询。 |

### 期限提示

初始确认5分钟，改办后已有草案期限10分钟，模拟验证最长2分钟，单次许可60秒，单笔后台委托30分钟。页面倒计时仅作提示，服务端实际状态为准。登录恢复不恢复旧确认、验证码或已经到期的许可。

## 累计阈值体验与提示解释

这里的“转账危险性累加”指已经受理的使用额会进入下一笔金额门槛判断。推荐先读例子与现成验证，现场只观察提示即可，不需要制造连续付款。

### 最简例子：900 + 200

若本人累计使用额已有900元，本笔准备200元，合计1100元，应触发Red金额强验证。它把连续操作放到同一用户的使用背景下，而非只看200元。统计还包括旧日仍处理中的出账，所以不一定等于今日页面成功流水合计。

| --- | --- | --- |

| 310.00元 | 690.01元 | 合计1000.01，Red |

### 共享账户不能承诺固定起点

例表来自隔离验证，不保证当前共享账户使用额为0或310。实际统计覆盖本演示系统可信来源内本人付款账户，按UTC+8首次受理日纳入当日成功与处理中出账，跨日仍处理中也保留；草案、未正式受理的预留和收入不算已受理出账。刷新、重新登录和新建聊天不会清零。

### 看懂提示与办理条件

Red表示金额最低要求提高，不代表硬拒绝、已经付款或完整风险评估。NOT_EVALUATED表示领域风险尚未评估，不能当作安全低风险。工具已有更高要求时仍取较高者，小额也按页面完成独立确认、模拟码、委托与许可。

### 观察到这里就可以停

可阅读例表，或按“大额提示与付款恢复”准备并确认未受理草案后查看警告；不要为了凑900元、310元或清占用进行新付款。资金受理前可明确放弃；已受理、处理中或未知继续查原号。八类设备/频次软信号属于底座扩展设计，当前网站未绑定，不要求您测试设备或频次。

## 订阅管理完整体验

演示服务包括“星河视频月度会员”和“悦听音乐月度会员”。示例名称为虚构；月费、日期、候选和已管理状态取决于当前本人资料，不能要求每次都有尚未登记的候选。

### 读取与登记

1. 进入订阅管理，点击“读取本人订阅”。若已有管理项，可直接选择它；没有时页面会说明当前暂无已管理订阅。
2. 点击“识别可登记订阅”，查看服务名称、重复扣费证据及候选状态。候选只代表待本人确认，不等于已开通新会员。
3. 对尚未登记的候选点击“准备登记”，核对安排后依次点击“确认此项订阅操作”和“保存订阅操作”。
4. 点击“查询办理结果”核对结果，再点击“已核对记录，准备下一项”。随后重新读取本人订阅，确认管理项状态。

### 提醒 取消意图与撤回

1. 在已管理订阅下点击“设置提前1天提醒”，按相同确认和保存步骤完成，再核对结果。只有可用服务日期支持的安排才应继续；日期缺失时不要自行补造。
2. 点击“记录取消意图”，确认并保存后核对状态。此操作仅保存本地意图，不会联系真实商户或停止真实扣费。
3. 核对该操作后准备下一项，点击“撤回取消意图”，重新确认并保存，查看状态恢复。
4. 点击“查询模拟提醒原尝试”查看已有模拟渠道记录；没有记录时可能尚未触发，不要当作外部通知失败或真实消息送达。

### 共享记录与异常恢复

如候选已由其他评委登记，请使用现有管理项体验提醒和取消意图，不重复登记。当前有未核对办理时，先查结果再准备下一项；服务重启造成旧准备失效时，页面允许“保留失效原记录，重新选择”，重新识别、准备和确认。结果未知时不要清编号或反复新建。

### 怎么看懂编号和状态

SUB 开头的是稳定办理编号，便于在办理记录中查询。待确认候选、本地已登记、已记录取消意图和模拟提醒已保存表示不同阶段。无可靠日期时显示待核对，不由模型猜下一次扣费时间。

## 账单反馈与银行卡

反馈记录用户对原交易的判断，主动冻结单独改变卡片安全状态。两项操作分别确认，不会因为选择“非本人交易”就自动冻结或撤销付款。

### 账单与反馈

1. 进入我的账单，读取月度账单并选择原报告中的一笔交易，核对日期、金额和商户。
2. 选择“本人交易”“非本人交易”或“不确定”，核对确认区信息，完成“确认保存本人判断”和“保存反馈”。
3. 使用“只读查询原反馈”或反馈历史核对保存结果。已有反馈可按页面更正或撤销，每次重新确认。
4. 更正保留原记录和修改历史；撤销仅取消当前意见，不撤销原交易、不自动冻结或解冻。撤销后可在原交易下重新提交，仍须重新准备并确认；每次用原反馈查询核对实际保存。

### 当前卡片状态

进入银行卡，点击“查询银行卡当前状态”，核对工资卡尾6628和关联账户出账限制。组织者已完成的一次解冻不保证您此刻仍无锁，以实时读取为准。卡可用时先完成付款体验再冻结；已冻结时先只读核对，不重复冻结或删除原锁。再次解冻需联系组织者按受控流程处理；原冻结历史不会被抹去。

### 卡可用时如何体验主动冻结

1. 在组织者确认可用的本人卡上，先完成需要成功出账的体验，再点击“准备本人主动冻结”。
2. 核对卡尾号、冻结原因、影响和解除说明，点击“确认冻结此卡”。
3. 领取本次卡片模拟验证码，将卡片专用挑战号与验证码手动填入对应框，点击“核验卡片验证码”。付款码不能用于冻结。
4. 点击“执行本人主动冻结”，再用“查询原卡操作”和当前状态核对。生效后关联账户出账受限，刷新或重新登录不应解除限制。

### 完成体验

再次读取余额、订阅和原业务记录，确认页面反映本次操作。退出登录不会删除历史或自动撤销仍有效的后台委托。需要协助时向组织者提供页面显示的办理编号、时间和现象，不发送口令或验证码。当前演示后台身份覆盖至北京时间2026年11月11日零点，之后体验由组织者安排。
